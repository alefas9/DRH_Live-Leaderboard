# Εικόνες πιλότων (manual)

Βάλε εδώ μια εικόνα ανά πιλότο. Θα εμφανίζεται μεγάλη και κεντραρισμένη
στην κορυφή του drawer (προφίλ) του.

## Ονομασία αρχείου

`<callsign>.png` — ακριβώς όπως γράφεται το όνομα στο leaderboard,
με κεφαλαία/πεζά όπως είναι. Παραδείγματα:

- `TettixPro.png`
- `DedalosFPV.png`
- `anthunder.png`

Αν κάποιος πιλότος δεν έχει εικόνα, εμφανίζονται αυτόματα τα αρχικά του
(όπως παλιά) — δεν σπάει τίποτα.

## Τεχνικά

- Τύπος: PNG (ή μετονόμασέ το — ο browser κρίνει από το περιεχόμενο,
  αλλά κράτα .png για συνέπεια)
- Τετράγωνη ή οριζόντια εικόνα — κόβεται αυτόματα (object-fit: cover)
- Προτεινόμενο μέγεθος: 400×400 ή μεγαλύτερο
- Μετά από κάθε προσθήκη: commit + push, και το Vercel το σερβίρει αμέσως
